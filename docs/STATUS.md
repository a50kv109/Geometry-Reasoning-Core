# Package status

This is a research-stage TypeScript package assembled from the `geometry-reasoning-core/` directory embedded in `Origami-Geometry-Core-main (7).zip`. The package includes 3D geometry model modules and a 2D reflection test/verifier subsystem. The branch-selection and domain modules are explicitly experimental.

No broad mathematical completeness or universal correctness claim is made. See `CORE_RELEASE_AUDIT.md` at the package root for the exact audit and command outcomes. Test status must be read from actual runs, not inherited project reports.
